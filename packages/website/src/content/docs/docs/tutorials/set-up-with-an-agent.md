Give your AI agent one line, and it sets fxbot up on your machine. Or give it all the docs as plain text.

## Set up fxbot

On the machine you want fxbot on, tell your agent:

```text wrap
Set up fxbot on this computer for me: follow https://fxbot.sh/agent-setup.txt
```

It checks the machine, asks before it installs anything, and leaves your keys and sign-ins to you. When it's done, carry on from [Set up fxbot](/docs/tutorials/first-fxbot/#set-up-fxbot), which then [puts fxbot on your phone](/docs/tutorials/first-fxbot/#put-it-on-your-phone).

## Give it the docs

**Copy all docs**, at the top of each page on a computer, copies them all, to paste into a chat. Or point your agent at the plain text:

| File | What's in it |
| --- | --- |
| [agent-setup.txt](https://fxbot.sh/agent-setup.txt) | The steps for an agent to install fxbot |
| [llms.txt](https://fxbot.sh/llms.txt) | A short index of the docs, to start from |
| [llms-full.txt](https://fxbot.sh/llms-full.txt) | All the docs in one file, about 400 KB |

Every page has a Markdown twin too, at its address with `.md` in place of the last slash, such as [/docs/how-to/update.md](https://fxbot.sh/docs/how-to/update.md). **Copy Markdown**, at the top of each page, copies it.
