# herdr screen

A herdr button next to Settings replaces the screen with the [herdr](https://herdr.dev) interface, to work with everything herdr runs. A status bar along the bottom of the app switches back to bot mode.

**Plugin.** Part of a herdr [plugin](../_completed/phases/plugins.md), which adds the button and the screen through the plugin API. The core never names herdr. The plugin itself, which gives bots herdr's agents as tools, is planned in [herdr](../_completed/phases/herdr.md). Its door on the machine takes no terminal stream, which this screen would need.

Not planned yet.
