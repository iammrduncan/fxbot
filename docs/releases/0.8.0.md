fxbot v0.8.0 is out!

https://fxbot.sh/docs/reference/changelog/

Before upgrading: the update adds two columns to your providers, for a provider's region or account and the models you type for it. Every provider carries on as it is. Then update Computer from Plugins, if you have it, and run sudo fxbot computer on once, which moves its lines out of compose.override.yaml. The update leaves 0.7.0's image behind: sudo podman rmi ghcr.io/iammrduncan/fxbot:0.7.0 (or docker rmi) frees it.

Changes:

- New Plugin: Web pairing => open your own fxbot on your phone or any computer at web.fxbot.sh, paired once with a code, over a connection straight to your fxbot
- A new page for adding a provider: sign-ins first, then a card for each key with where to make it, the clouds, and servers on your own machine
- Sign in to OpenRouter, OrcaRouter, and Hugging Face, with nothing to paste
- About 40 providers, each with a page in the docs, and the list of them updates without a release
- fxbot installs on Fedora, AlmaLinux and the other RHEL rebuilds, openSUSE, and Arch, beside Debian and Ubuntu (Arch thanks to Olen Thompson)
- The install checks your machine first, and stops with what to do when it can't install there
- sudo fxbot backup, and sudo fxbot uninstall, which keeps a backup and your key unless you add --purge
- The computer runs on every engine, so Ubuntu 24.04 with docker.io gets one (with Computer 0.3.2)
- Install on another port than 8787, with FXBOT_PORT
- Skip for now skips one step of first-run setup, not all of it
- Bug fix: a wrong OpenRouter key is refused when you add it, not at your first message
- Bug fix: an install behind ufw on podman reaches its database again (run sudo fxbot up once after updating)
- Bug fix: the computer's setup works on a Debian without systemd-resolved (with Computer 0.3.2)
