fxbot v0.10.0 is out!
fxbot: AI assistants that do real work, built your way.

https://fxbot.sh/docs/reference/changelog/

Before upgrading: if you have chat-rooms-computer, keep it until fxbot and Computer are both updated. Update fxbot first, then Computer from Plugins, then remove chat-rooms-computer: each room keeps its computer. Removed before Computer is updated, it takes the rooms' computers and their files with it. Remove the fresh plugin too, as /fresh is built in now. The update adds a thinking level to each bot, lets a memory belong to every bot, and turns on idle compaction, so in the first minutes after it each long chat that's been idle is summarized once with its bot's own model, and each long room by its lead once Chat rooms is updated; turn it off in Settings › General if you'd rather it didn't. Then update Subagents and Chat rooms from Plugins.

Changes:

- New Plugin: Soul => each new bot meets you first, guesses who it is from its name, and writes a few lines of who it is and how it helps you, which it keeps up when you ask; bring a soul over from Hermes Agent, OpenClaw, Grok Bot, ChatGPT, or Claude
- Choose how hard a bot thinks: Thinking, on its edit screen, offers the levels its model has, and Subagents get a level of their own
- Team memories: notes every bot reads, kept in Settings › Memory, and any bot's own memory can be shared with every bot
- A room's memories: notes every bot in a room reads there, which the room's bots save too (with Chat rooms 0.5.0)
- Idle compaction: a long chat left idle for 30 minutes is summarized while you're away, so your next message starts fast
- A room starts over as a bot's chat does: idle compaction and /fresh, from one summary for the whole room (with Chat rooms 0.5.0)
- Send PDFs to a bot: it reads their text, and the library keeps the PDF
- /fresh is built in, in every bot's chat, with nothing to add
- A room's computer is part of the computer now (with Computer 0.5.0), and chat-rooms-computer retires
- Claude with prompt caching: add Claude through AI Gateway with your own Anthropic key
- Bug fix: a bot's chat summary stays in its own chat, not in its rooms, routines, and subagents
- Bug fix: deleting a room while a bot answers there no longer stops fxbot (with Chat rooms 0.5.0)
- Bug fix: web.fxbot.sh connects again after a computer wakes up
- Bug fix: no more thin box around a moving bot in Firefox
