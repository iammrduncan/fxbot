fxbot v0.11.0 is out!
fxbot: AI assistants that do real work, built your way.

https://fxbot.sh/docs/reference/changelog/

Before upgrading: the update adds one setting, how long a chat must be before it's compacted while idle, kept at about 30,000 tokens as before. Then update Chat rooms, Messages, Permissions, Computer, and Web pairing from Plugins. For herdr's screen and keys on a release install, run sudo fxbot herdr on again after the update: it opens herdr's own screen to fxbot's page, which can open a shell as herdr's user, and needs python3 on the machine. Add --read-only to keep that shut.

Changes:

- New Plugin: herdr => your bots see the coding agents herdr runs, here and on your saved machines, send them work, start new ones, and hear back when one's done; herdr itself opens in the sidebar, in a real terminal, from your phone too
- Tag a herdr agent in a chat with @herdr:, and the bot knows exactly which one you mean (with Messages 0.2.1)
- New Plugin: Phone => press Call me and a bot rings your phone and talks with you, hands-free, through SignalWire with the phone-signalwire plugin
- Choose how long a chat must be before it's compacted while idle, in Settings › General
- Baseten, by key, on Add provider
- A bot that asks other bots answers you once they've all replied (with Messages 0.2.1)
- The app opens faster, and one of your bots bounces while it loads
- A bot hands you an "I'm not a robot" check at once, to tick yourself (with Computer 0.5.1)
- Bug fix: a chat opens at its newest message
- Bug fix: "Cannot reach the server" no longer stays until fxbot restarts
- Bug fix: a permission card shows without reloading the page (with Permissions 0.1.2)
- Bug fix: an error while the app draws shows what broke, with Reload, not a white screen
- Bug fix: one plugin's failing promise no longer stops fxbot
